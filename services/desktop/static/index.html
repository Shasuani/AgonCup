LeagueOfLeagues — Match Runner

This client autonomously runs each custom match via your local League client (LCU). It connects to the backend per assigned match, drives the lobby (host: create & invite by PUUID; guest: auto-accept), and reports live + end-of-game stats for cross-client corroboration. It never automates in-match gameplay.
