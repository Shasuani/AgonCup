Step 01 — Authenticate

Enter Pairing Code

Run /register in Discord for a one-time code, then enter it here. The code is the credential — no permission screen, and you stay signed in across restarts.

Step 02 — Link Account

Link League Account

Make sure League of Legends is open and you're fully signed in. We read your local client to confirm your Riot ID — read-only, never any in-game automation. Got more than one account? Switch your League client to it and verify again — each is linked separately.
