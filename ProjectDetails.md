Project: AgonCup
Description: Tournaments for Leauge of Legends, up to 16 teams per tournament, running in paraller multiple tournaments, user registration and tournament status throught discord. 
One backend preferred in Python.
One Discord bot for user registration, tournament join.
One Windows/Mac client that connects to collect data from Leauge client ,status and validation of user account, live updating statistics and states of the game.
One administration frontend with CRUD support for accounting, tournaments etc.
API Leauge support if needed.
We want other Discord servers to be able to invite the bot to their discord , so they can create their own tournamets that should be optional available in League Of Leauges discord server as well.
