## 2. Match-ready gate — 5λεπτο ready (§0.2 / §8.5) 🟢
- **Migration 0012:** νέα columns στο `matches` (`ready_deadline_at`,
  `team_a_ready_at`, `team_b_ready_at`).
- **`POST /tournaments/matches/{id}/ready`** — ο team captain πατάει ready
  (403 αν δεν είναι captain, idempotent).
- **`run_readiness_tick`** (στο app lifespan loop, 5' μέσω `ready_window_seconds`):
  οπλίζει το window μόλις είναι και οι 2 ομάδες παρούσες· στο deadline → μία ready +
  άλλη όχι = **walkover** στην έτοιμη· καμία = re-arm.
- Νέο module `app/tournaments/readiness.py` + 10 offline tests.

## 3. Autonomous auto-lobby μόλις κάνουν ready και οι 2 (§8.1–8.2) 🟢
- **`auto_initialize_lobby`**: μόλις πατήσουν ready και οι 2 ομάδες, πυροδοτείται
  αυτόματα το lobby (host succession → `CreateLobby` + `Invite`) — **όχι πια μόνο
  admin**. Best-effort (αν κανείς δεν έχει host opt-in, το ready στέκει).
- Το game-status reporting (heartbeat/phase) + auto-join sequencing **υπήρχαν ήδη**.

## 4. Live status στο Discord (§9.2) 🟢
- Milestones (όχι spam) στο guild notify channel μέσω `tournament_announced`:
  **ready-up, walkover, lobby-open, 🔴 now-live, result**.
- Νέος best-effort `_announce_phase` στο orchestration (lobby-open + in-game).

## 5. Desktop — κουμπί «Ready up» + wait-for-opponent (§8.5 UI) 🟢
- Το bracket API πήρε `id` + ready state (`ready_deadline_at`, `team_a/b_ready`).
- Στο bracket accordion: ο captain κάθε πλευράς βλέπει **«Ready up»** + countdown
  («X min left») + κατάσταση αντιπάλου (✓/•)· «Waiting for the other match's
  winner…» όταν ο αντίπαλος δεν έχει κριθεί.
- `markReady` → IPC → `POST /matches/{id}/ready`. +3 desktop tests.

## 6. Έρευνα: Tournament Codes vs Custom — **απόφαση: CUSTOM ONLY** ❌→✅
- Έρευνα (Riot DevRel / Reddit / Battlefy-Challengermode) έδειξε ότι υπάρχει
  επίσημος δρόμος (**Tournament Codes**: auto-lobby + authoritative result callback)
  — η υπόθεση «no Tournament API» ήταν λάθος.
- **Απόφασή σου: το ξεχνάμε, μένουμε 100% σε custom lobbies (autonomous-LCU).**
- Κρατήθηκε ως research record: `docs/decision-tournament-codes.md` (marked REJECTED).

## 7. Transfer captaincy + audit edge cases §1–§7 🟢
- **`POST /teams/{id}/transfer-captain`** (`transfer_captain`): ο captain δίνει την
  αρχηγία σε άλλο active μέλος και μετά μπορεί να φύγει (λύνει το §1.4 dead-end).
  +5 tests.
- Audit §1–§7: τα περισσότερα ήταν **ήδη καλυμμένα** (idempotent join, cascade
